# Alerta y Preparados — Android

Proyecto Android inicial basado en el prototipo recuperado del proyecto.

Incluye actualmente las secciones recuperadas: emergencia, preparación, plan familiar, señales de la naturaleza, guías de prevención y mochila de emergencia, con contenido pensado para consulta sin conexión.

La interfaz del prototipo se empaqueta dentro de una aplicación Android mediante WebView para conservar el funcionamiento existente mientras se continúa el desarrollo nativo.

Estado: proyecto Android preparado; el APK final requiere un entorno Android/Gradle con SDK instalado para compilarlo.
